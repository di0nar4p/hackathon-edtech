# ⚡ NeuroLearn AI - Plataforma de Estudo Adaptativo

> Protótipo de interface web desenvolvido como estrutura base para o **Hackathon Sintechtica 2026** (Ânima Educação).

---

## 🎯 Sobre o Projeto

O **NeuroLearn AI** é uma proposta de plataforma educacional (*EdTech*) focada na personalização do aprendizado através da aplicação de conceitos de **Inteligência Artificial** e **Neurociência**. 

O objetivo do sistema é auxiliar estudantes a otimizarem o tempo de leitura e a fixação de conteúdo, transformando textos longos em resumos adaptativos de rápida retenção.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da página.
- **CSS3**: Estilização moderna com suporte a *Dark Mode* (Modo Escuro) e layout responsivo.
- **JavaScript (ES6+)**: Interatividade e simulação do fluxo de geração de conteúdo por IA.

---

## 🎨 Funcionalidades da Interface

- 🌙 **Interface Moderna em Dark Mode**: Design escuro focado no conforto visual para longas rotinas de estudo.
- 📱 **Layout Responsivo**: Componentes adaptáveis para diferentes tamanhos de tela.
- 🧠 **Simulador de Resumo Inteligente**: Campo interativo para demonstração do fluxo de processamento de textos com IA.
